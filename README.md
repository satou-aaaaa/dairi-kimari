# 代理のきまり（dairi-kimari）

代わりに買ってもらった契約はだれの物？頼んでいない人が勝手に契約したら？だれかに代わりに契約してもらう・勝手に契約された場面を見て、民法の代理の決まりどおりの答え（だれの契約になるか・取り消せるか・責任を負うか）を選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/dairi-kimari/>

- 答えは、e-Gov 法令検索の民法（<https://laws.e-gov.go.jp/law/129AC0000000089>）の条文（第99〜118条。2026年11月17日に読んだ、2026年6月24日の版）で確かめたことだけです。
- 人の名前・品物・金額は作り話です。判例・商法や会社法など、ほかの法律の決まり・成年後見の手続きは、このゲームでは答えにしません。「知っていた」「不注意があった」などは、問題の中で言い切ります。一人ずつの事情の判断も答えにしません。
- このゲームは民法の代理のきほんを知る練習です。法律の助言ではありません。公式の情報の代わりではありません。自分の場合どうなるかは、消費者ホットライン188（いやや）や法テラス・専門家に確かめてください。 消費者ホットライン: <https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/> 法テラス: <https://www.houterasu.or.jp/>
